# Web-Layout-Lab

## 1. Про проєкт
Навчальний вебпроєкт, створений для відпрацювання навичок семантичної верстки та стилізації вебсторінок. Проєкт демонструє структурування контенту за допомогою HTML5 та оформлення макета засобами CSS3 із розділенням коду на окремі файли.

## 2. Використані технології
* **HTML5** — створення семантичної структури сторінки та таблиць.
* **CSS3** — стилізація елементів, позиціонування та робота з сітками.
* **Photopea** — підготовка та оптимізація графічних зображень.
* **Git & GitHub** — контроль версій та розміщення репозиторію.

## 3. Функціональність
* Валідна та семантично правильна розмітка сторінки.
* Повне розділення структури (HTML) та таблиць стилів (CSS).
* Структуроване відображення даних та графічних елементів.
